# Data Directory

This folder is used to store the dataset required for this project.

Due to GitHub file size limits, the dataset is not included.

Please download the dataset from:
https://ftp.ncbi.nlm.nih.gov/geo/series/GSE68nnn/GSE68848/matrix/GSE68848_series_matrix.txt.gz

After downloading:
1. Extract the .gz file
2. Place the .txt file in this directory
3. Ensure the filename is:
   GSE68848_series_matrix.txt
